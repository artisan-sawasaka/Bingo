## 手動確認手順（実機）

1. PC で起動 → 最大番号 75 で開始 → `Q` でQR表示。
2. iPhone のカメラでQRを読む → Safari でリモコンが開き「抽選できます」になる。
3. レバーを半分引いて離す → 戻るだけで抽選されない。
4. 最後まで引いて離す → テレビで約2.4秒の演出 → 番号表示。スマホにも同じ番号。
5. 演出中にもう一度引く → レバーが震えて無効。
6. iPhone を画面ロック → 10秒後に解除 → 自動で再接続し同じ状態。
7. PC の Wi-Fi を一時切断 → スマホが「切断 — 再接続中」→ 復帰後に同じ状態。
8. PC アプリを終了 → 再起動 → 「前回のゲームを復元しました」→ スマホは自動再接続。
9. 75球すべて引く → 「全ての番号が出ました」。76回目は引けない。
